# Golden-Agent

Crate-level rules for the agent framework. Project-wide rules live in the root `AGENTS.md`.

- Examples need `DEEPSEEK_API_KEY` and network access to run.
- Run this crate's tests with `cargo test -p golden-agent`.
- When asked to modify or add a feature, implement it directly. Do not add a dedicated
  `README.md` / `README_zh.md` section that introduces the feature and walks through examples
  unless explicitly requested; keep the Features list in both READMEs in sync instead.
